# ROM // Рен

Текстовая rogue-lite RPG по мотивам «Нейроманта». Фан-проект, некоммерческий.

Ты — ROM-конструкт умершего ковбоя. Каждый забег — одна загрузка. ROM не должен помнить между загрузками. Ты помнишь.

## Документация

- `docs/world.md` — мир, время действия, право, тон
- `docs/characters.md` — восемь персонажей, мотивации, цели, связи
- `docs/run-loop.md` — петля забега, ресурсы, память как механика
- `docs/acts-and-endings.md` — сцены-ключи по актам и пять концовок

## Запуск

```
npm install
npm run dev
```

Сборка для GitHub Pages:

```
GH_PAGES_BASE=/neuromancer-rogue/ npm run build
```

Статика в `dist/`. Прогресс хранится в localStorage браузера.

## Структура

- `src/engine/` — движок: типы, состояние, переходы. Не знает о сюжете.
- `src/content/` — сцены. Акт I написан, акты II–III в планах.
- `src/ui.ts` — рендер в DOM.

## Статус

Прототип: акт I играбелен, включая узел Тишины и встречу с Марш при накопленной памяти.

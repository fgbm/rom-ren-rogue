# ROM // Рен

Текстовая rogue-lite RPG по мотивам «Нейроманта». Фан-проект, некоммерческий.

Ты — ROM-конструкт умершего ковбоя. Каждый забег — одна загрузка и один заказ. ROM не должен помнить между загрузками. Ты помнишь.

## Документация

- `docs/world.md` — мир, право, тон, регистры текста
- `docs/characters.md` — пятнадцать персонажей, мотивации, связи
- `docs/locations.md` — граф локаций трёх городов
- `docs/orders.md` — каталог заказов: восемь заказчиков, 36 заказов, лестница памяти
- `docs/acts-and-endings.md` — ключевые сцены и пять концовок
- `docs/run-loop.md` — петля забега, ресурсы, режиссёр
- `docs/rom-language.md` — язык сценариев `.rom` и правила линта
- `docs/writing-guide.md` — гид сценариста

## Запуск

```
npm install
npm run dev
```

Сборка для GitHub Pages:

```
GH_PAGES_BASE=/neuromancer-rogue/ npm run build
```

Статика в `dist/`. Прогресс хранится в localStorage браузера.

## Сценарий

Весь контент лежит в `content/**/*.rom` на собственном языке сценариев. Файлы компилируются Vite-плагином в JSON при сборке и проверяются линтом: ссылки, достижимость, циклы, тупики, имена говорящих, пороги памяти.

```
npm run lint       # проверить сценарий, код выхода 1 при ошибках
npm run stats      # таблица по заказам: сцены, выборы, доля тупиков, слова
npm run graph      # content/graph.scenes.dot и content/graph.locations.dot для Graphviz
npm run simulate   # случайный проходчик: 200 забегов, статистика выгрузок и покрытия
```

Структура контента:

- `content/registry.rom` — служебные сцены, пороги памяти, предметы, персонажи, фракции, заказчики
- `content/meta.rom` — загрузка, выгрузка, перехват, осыпание, стирание
- `content/keys.rom` — общие ключевые сцены: первый узел Тишины, торг Виейры
- `content/library.rom` — библиотека и пять концовок
- `content/locations/` — локации трёх городов с сухим и развёрнутым описанием и событиями пула
- `content/orders/` — один файл на заказ

## Код

- `src/rom/` — компилятор: парсер, выражения, линт, граф. Не знает о браузере.
- `src/engine/` — движок: состояние, интерпретатор, режиссёр по локациям. Не знает о сюжете.
- `src/ui.ts` — рендер в DOM.
- `scripts/` — CLI линта и симулятор. Запускаются Node без сборки.

Отладка из консоли браузера: `game.state`, `game.goto("id_сцены")`, `game.enterLoc("id_локации")`.

## Статус

36 заказов у восьми заказчиков, около 600 сцен, 31 локация, пять концовок. Игрок передвигается сам, карты на экране нет. Не менее пятой части выборов в каждом заказе ведут в тупик.

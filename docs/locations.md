# Локации

Игрок передвигается сам. Карты на экране нет: только описание места и именованные выходы. По кнопке «где я была» доступен список посещённых локаций текущего забега без связей. Если игрок хочет карту, он чертит её сам.

Граф локаций может содержать циклы: это пространство. Граф сцен циклов не содержит: это сюжет.

## Правила

- Каждая локация имеет `dry` и `rich` описание. Сухое короче в два-три раза, без эпитетов, перечислением. Развёрнутое с запахом, температурой, звуком, износом.
- В развёрнутом описании допустимы блоки `? if memory >= n`: с ростом памяти Рен видит больше. Не больше деталей на экране, а больше связей: «ты знаешь, сколько ступеней».
- Событие пула (`pool`) привязано к локации. Всё, что не может правдоподобно повториться (смерть, первая встреча, единственный предмет), помечается `once`.
- Переходы между городами только через космопорты и только с листом, билетом, бумагой Марш или дабом. Иначе выход скрыт.
- Тупиковые локации (`bama.sump`, `straylight.dead_a`, `straylight.dead_b`) существуют, чтобы игрок ошибался. В них есть что-то одно, и оно не стоит визита. Иногда стоит.

# Каталог заказов

Забег это один заказ. Виейра грузит Рен, называет заказчика и задачу. Заказ определяет стартовую локацию, условие выполнения и сцену развязки. Всё остальное игрок делает сам: куда идти, с кем говорить, что покупать.

Заказы открываются лестницей: по выполненным заказам, по памяти, по репутации. Одного заказчика можно выбирать много раз, но заказ выполняется один раз. Заказ, проваленный выгрузкой, остаётся доступным. У заказа с отказами (`dead:refusal`) есть сцена `fail` и след: репутация заказчика вниз, фрагмент памяти и пометка «(сорвано)» на экране выбора.

Каждая строка это бриф для сценариста. Обязательные поля: старт, `done`, развязка, что заказ приоткрывает о нижнем слое (Тишина кормит Рен памятью, Морияма ошибается, Марш ищет ядро), минимум два тупика. Если в заказе есть отказ (`dead:refusal`) — ещё и поле `fail` со сценой провала.

Правило повторяемости: сцена, которая не может случиться дважды (смерть соседа, первая встреча, единственный предмет), помечается `once`. Сцена, которая правдоподобно повторяется (патруль, торг, дождь), может быть в пуле без `once`, но тогда её текст должен учитывать `seen()` и не делать вид, что это впервые.
